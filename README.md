# online-job-portal-system

A full-stack Online Job Portal built using Java, Spring Boot, MySQL, REST APIs, and Maven.

\# Online Job Portal System



\## Project Description

Online Job Portal is a Spring Boot based web application that allows users to register, companies to post jobs, and users to apply for available jobs.



\## Technologies Used

\- Java 17

\- Spring Boot

\- Spring Data JPA

\- Spring Security

\- Hibernate

\- MySQL

\- Maven

\- Swagger API Documentation

\- Lombok



\## Features



\### User Module

\- User registration

\- User login authentication

\- User management



\### Company Module

\- Add company details

\- View companies

\- Manage company information



\### Job Module

\- Post jobs

\- View available jobs

\- Manage job details



\### Application Module

\- Apply for jobs

\- View applications

\- Manage job applications



\## API Documentation

Swagger UI is used for API testing and documentation.



\## Database Tables

\- Users

\- Companies

\- Jobs

\- Applications
